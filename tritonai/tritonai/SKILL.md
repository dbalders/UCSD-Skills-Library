# TritonAI

TritonAI is UC San Diego's campus AI program. It provides TritonGPT, AI training and support, and resources for building with the TritonAI Harness, workflow automation, shared APIs, and campus skills.

## Find current information

- Start with [TritonAI](https://tritonai.ucsd.edu/) for service overviews, training, access, policy, and campus updates. Use [Build with TritonAI](https://tritonai.ucsd.edu/developer-apis/index.html) for the building paths and [trust, privacy, and hosting](https://tritonai.ucsd.edu/about/trust-architecture.html) for data guidance.
- Use [TritonAI Docs](https://docs.tritonai.ucsd.edu/) for technical setup, the Developer API, tool connections, and n8n guidance. Its [documentation index for agents](https://docs.tritonai.ucsd.edu/llms.txt) helps locate relevant pages.
